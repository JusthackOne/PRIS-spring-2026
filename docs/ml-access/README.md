# Кейс №2 Идентификация сотрудников по лицу на проходных предприятия

**Автор:** Недиков Михаил Олегович. Индивидуальный проект.  
**Роли:** Product Owner, Data Engineer, Data Scientist, Software Architect, Data Architect.  
**Продукт:** «Контур доступа». **Итерация:** MVP 1 с проектом промышленного развёртывания.  
**Тип работы:** проектирование информационной системы с ML. **Версия:** 1.0, 25 сентября 2026 года.

## Комплект работы

Основной документ — [ML System Design Document](ML_SYSTEM_DESIGN.md). Он содержит требования, методологию ML, план пилота, архитектуру, расчёт нагрузки, безопасность, издержки и риски. Структура соответствует присланному шаблону Reliable ML; повторяющиеся номера последних подразделов шаблона исправлены на 4.7 и 4.8.

- [Отчёт в PDF](../../REPORT_4.pdf) и [редактируемый отчёт Word](../../REPORT_4.docx).
- [Каталог диаграмм с описаниями](diagrams/README.md): процессы AS-IS и TO-BE в IDEF0, ER, архитектура, UML компонентов, UML последовательности, алгоритмы baseline и MVP.
- [Исходное задание](sources/assignment.txt) и [полученный шаблон MLSD](sources/mlsd-template.md).

Документ описывает проектируемую систему. Код распознавания, фотографии работников, обученные веса и результаты реального пилота в комплект не входят. Из исходного кейса известны только 5000 сотрудников, 10 проходных и существующий порядок проверки пропуска охранником. Остальные численные параметры явно обозначены как проектные цели или допущения.

Согласование индивидуального выполнения с преподавателем остаётся организационным условием задания. Автор выполняет все перечисленные роли; фактическое согласование в документах не утверждается.

## Просмотр и воспроизводимость

Все диаграммы встроены в основной документ как PNG и доступны отдельными файлами с описаниями; SVG позволяют увеличить схему без потери качества.

Исходники диаграмм находятся в `diagrams/src`, генераторы — в `tools`. Порядок пересборки приведён в [tools/README.md](tools/README.md). Ветка работы: `project/ml-access-case2`. Ветка содержит только материалы по кейсу №2.
